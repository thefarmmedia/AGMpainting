# AGM Painting LLC: Website

Static, SEO-focused site for AGM Painting (Springfield, MO). No framework and no runtime dependencies. Plain HTML, CSS and JS, generated by a small Node script.

## Edit & rebuild
- **All copy lives in `tools/data.mjs`** (business info, services, service areas, reviews, FAQs).
- Rebuild the pages: `node tools/build.mjs`
- New photos: drop them in `_originals/`, add them to the `MAP` in `tools/images.py`, then run `python tools/images.py`.

## Before launch
1. Set the real domain in `tools/data.mjs` → `BIZ.site`, then rebuild (this updates the canonical URLs, sitemap and schema).
2. Contact form uses FormSubmit.co. The **first** form submission sends Anthony an activation email, which he must click. Afterwards you can swap the email in `BIZ.formAction` for the random alias FormSubmit provides.
3. Host the repo root on Netlify, Cloudflare Pages, Vercel or GitHub Pages (custom domain). `404.html` is included.
4. Submit `/sitemap.xml` in Google Search Console, and add the website URL to the Google Business Profile.
